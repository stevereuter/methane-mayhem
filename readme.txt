Introduction
Methane Mayhem is a puzzle game written in BASIC where you have to complete a connection between two points using random pipe sections. It's turn based with a time limit. The left side of the screen contains a timer. The time will start full and drop on each turn. Once at the bottom it will start to rise again. Reaching back to the top will fail the level. The timer initially represents the time until the pipe start to leak, and then how much has leaked as it rises.

The game has a main game area in the middle of the screen and a tool section on the right. There is a indicator in each section to show the player what is currently selected. Use WASD to move the indicator in the main play area, and numbers 1 through 4 to select the pipe or tool. The pipe above the right section is the next pipe to use.
